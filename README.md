## 📝 Getting Started

To run the programs in this repository:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Reet-Kamlay/java-tutorials.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd java-tutorials
   ```
3. **Open the project in IntelliJ IDEA**:
   - Open IntelliJ IDEA.
   - Click on `File` > `Open`.
   - Navigate to the cloned `java-tutorials` directory and select it.
4. **Run the program**:
   - Open `Main.java` located in the `src` directory.
   - Click the `Run` button or use the shortcut `Shift + F10`.
